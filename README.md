# VLSI Design Internship – Task 1

## Introduction

This repository contains my submission for **Task 1** of the **Maincrafts VLSI Design Internship**. The objective of this task was to understand the VLSI Design Flow and implement fundamental digital logic circuits using Logisim. The report includes the implementation and verification of basic logic gates along with the design and simulation of a Half Adder.

## Topics Covered

- VLSI Design Flow
- Digital Logic Fundamentals
- Logic Gates and Truth Tables
- Half Adder Design and Simulation

## Tools Used

- Logisim
- PDF Documentation

## Repository Contents

- **VLSI_Task1.pdf** – Complete technical report
- **Logic_Gates.png** – Logic gate simulation
- **Half_Adder.png** – Half Adder simulation

## Learning Outcomes

This task strengthened my understanding of digital logic design, truth table verification, combinational circuits, and circuit simulation using Logisim. It also provided practical exposure to the fundamentals of the VLSI design flow.
